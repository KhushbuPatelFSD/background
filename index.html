💡 What to Observe:
  • background-size: See how the pattern scales — cover fills, contain fits, auto keeps original, 100% 100% stretches.
  • background-position: Moves the pattern to corners, center, or edges.
  • background-attachment:
    • scroll → pattern moves with the page.
    • fixed → pattern stays still (try scrolling the page).
    • local → scroll inside the box to see the pattern move.
  • background-repeat: Controls whether the pattern tiles — repeat, repeat-x, repeat-y, or no-repeat.
